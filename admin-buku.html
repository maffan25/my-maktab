Kelola Perpustakaan

Tambah buku, ganti sampul, ubah nama folder, atau hapus buku. Tidak perlu coding. Selesai mengedit, tekan tombol unduh lalu unggah hasilnya ke GitHub.

Cara menerbitkan perubahan
  1. Tekan + Tambah buku, pilih file PDF. Sampul dan jumlah halaman terisi otomatis dari halaman pertama PDF. Boleh ganti dengan foto sampul sendiri.
  2. Ganti nama folder dengan mengetik langsung pada namanya. Pindahkan buku lewat Ubah, lalu pilih folder lain.
  3. Selesai? Tekan Unduh di bagian atas. Bila ada PDF baru, hasilnya berupa file zip. Ekstrak sehingga muncul buku.js dan folder buku.
  4. Buka repositori di GitHub, tekan Add file, lalu Upload files. Seret buku.js dan folder buku sekaligus, lalu Commit changes.
  5. Tunggu 1 sampai 2 menit, lalu muat ulang web. Satu file lewat browser maksimal 25 MB, yang lebih besar diunggah lewat GitHub Desktop.
  6. Jangan ubah judul atau penulis buku yang sudah banyak dibaca, karena favorit dan progres pembaca di perangkat mereka akan ikut terlepas.
